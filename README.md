## 📌 What this repository is

This repository contains my projects and learning work as a **Software Engineering student at 1337 (42 Network)**.

The 42 curriculum is built to develop strong fundamentals in:
- low-level programming in **C**
- **Unix/Linux** tools and system calls
- memory management and debugging
- concurrency and synchronization
- networking fundamentals
- engineering discipline (clean code, constraints, peer evaluation)

My personal goal is to use the Common Core to build a **systems-first foundation**, and then extend it toward **security-oriented engineering**.

## 🗂 Repository structure (explained)

This repo is intentionally split into 4 areas:

### 1) `common-core/` — Official 42 projects
This folder contains the official curriculum projects (e.g. **libft**, **ft_printf**, **minishell**, **philosophers**, **netpractice**, …).  
Each project folder should include:
- a short README (goal, constraints, key concepts)
- a clean build/run section
- notes on what I learned (debugging, edge cases, design decisions)

### 2) `advanced-systems/` — Systems depth beyond the curriculum
This folder contains self-driven projects inspired by the 42 methodology to deepen OS and performance understanding, such as:
- memory allocator experiments
- concurrent servers
- process monitors
- network scanners
- small storage/DB engines

The aim here is to go beyond “it works” and focus on:
- performance trade-offs
- correctness under stress
- observability and tooling
- failure modes and hardening

### 3) `security-oriented/` — Security extensions (ethical labs)
This folder contains security-oriented experiments designed for **controlled environments only**, such as:
- binary inspection/exploration tooling
- tracing/debugging tools
- vulnerable lab services (educational)
- OS-security focused labs

### 4) `docs/` — Learning notes and tracking
This folder contains notes and maps that document progression, including:
- a cursus roadmap
- a skills matrix
- project notes and lessons learned
