# 📚 Data Archivist – Digital Preservation in the Cyber Archives

## 🧠 Project Overview

In the year 2087, humanity’s most valuable resource is **data**.  
This project simulates the training of a **Data Archivist**, responsible for preserving, securing, and recovering digital knowledge inside the Cyber Archives.

Through a series of exercises, this project introduces **fundamental file operations in Python**, focusing on safety, correctness, and professional practices required in real-world systems.

The project is structured as **5 progressive exercises**, each building on the previous one.

---

## 🛠️ Technical Requirements

- **Language:** Python 3.10+
- **Code style:** flake8 compliant
- **Type hints:** Required for all functions
- **Authorized tools:**  
  - `open()`, `read()`, `write()`, `close()`
  - `print()`, `input()`
  - `sys.stdin`, `sys.stdout`, `sys.stderr`
- **Key concepts:**
  - File I/O
  - Stream separation
  - Context managers (`with`)
  - Error handling (`try / except`)
